# 変更履歴

## [2.0.0] - 2024-12-09

### 🔴 重大なバグ修正
- **11月データ消失問題を修正**
  - 7日間フィルタを削除し、過去データも全て保持するように変更
  - `run()` 関数から `inDateWindow()` チェックを削除

### ✨ 新機能
- **自動バックアップ機能**
  - 処理実行前に自動でバックアップを作成
  - 「予約履歴_バックアップ」シートに保存
  - タイムスタンプ付きで管理

- **手動バックアップ機能**
  - メニューから「💾 手動バックアップ作成」で手動実行可能
  - 重要な操作前のバックアップに使用

- **バックアップ復元機能**
  - メニューから「🔄 バックアップから復元」で簡単に復元
  - 確認ダイアログ付きで誤操作を防止

### 🔧 改善
- **dedupeDest()の安全性向上**
  - `clearContents()` から `deleteRows()` に変更
  - データ消失リスクを大幅に低減
  - より安全なシート操作

- **メニューの改善**
  - バックアップ関連メニューを追加
  - 機能別にセクション分け

### 📚 ドキュメント
- `README.md` を追加
  - セットアップ手順
  - 使い方ガイド

  - 問題の原因説明

  - 今後の予防策

  - バージョン管理の開始

## マイグレーションガイド（v1.0.0 → v2.0.0）

### 1. データの確認
まず、現在のデータをバックアップしてください：
- Googleスプレッドシートの「ファイル」→「コピーを作成」
- または変更履歴から復元ポイントを確認

### 2. コードの更新
1. GASエディタで既存のコードを全て削除
2. `予約履歴システム_修正版.gs` の内容を貼り付け
3. 保存

### 3. テスト実行
1. メニューから「今すぐ実行 (安全版/ロック付き)」を実行
2. エラーがないことを確認
3. データが正しく追加されることを確認

### 4. ライブラリのデプロイ
1. 「デプロイ」→「デプロイを管理」
2. 編集 ✏️ をクリック
3. バージョンを「新バージョン」に変更
4. 説明：「v2.0.0: データ消失バグ修正 + バックアップ機能追加」
5. デプロイ

### 5. 各店舗での更新
各店舗のスプレッドシートで：
1. ライブラリのバージョンを最新版に更新
2. テスト実行して動作確認

### 6. データの復旧（必要な場合）
11月のデータが消えている場合は、`データ復旧手順.md` を参照してください。
