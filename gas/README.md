# 予約履歴システム（データ集積用ライブラリ）

## 📌 概要

このシステムは、11店舗の日報システムから予約データを集積するGoogle Apps Script（GAS）ライブラリです。

### 主な機能

- ✅ 各店舗の「シート2」から予約データを自動取り込み
- ✅ 「予約履歴_蓄積」シートに全データを保存（キャンセル含む）
- ✅ 重複データの自動除去（最新データを保持）
- ✅ 5分ごとの自動実行（トリガー設定）
- ✅ 自動バックアップ機能
- ✅ ロック機能で同時実行を制御

---

## 🚀 セットアップ

### 1. ライブラリのデプロイ

1. GASエディタで「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」⚙ で「ライブラリ」を選択
3. 「デプロイ」を押して、表示される**スクリプトID**をコピー
4. このIDを11店舗の日報システムに「ライブラリ」として登録

### 2. コード更新時の手順

1. コードを修正
2. 「デプロイ」→「デプロイを管理」をクリック
3. 編集 ✏️ をクリック
4. バージョンを「**新バージョン**」に変更
5. デプロイ

### 3. 自動実行の設定

1. スプレッドシートを開く
2. メニューから「予約履歴_蓄積」→「⚙️ 自動実行ON (5分ごと)」を実行
3. 権限を承認

## 🔧 修正版の変更点（重要）

### ⚠️ 旧バージョンの問題

1. **7日間フィルタ**：過去7日より古いデータが追加されない
2. **データ消失リスク**：`clearContents()` による全消去処理
3. **バックアップなし**：データ消失時の復旧手段がない

### ✅ 修正版で改善された点

1. **日付フィルタを削除**
   - 過去データも含めて全て保持
   - 11月のデータも正しく保存される

2. **安全な重複削除**
   - `deleteRows()` を使用してリスク低減
   - データ消失の可能性を最小化

3. **自動バックアップ機能**
   - 処理実行前に自動でバックアップ作成
   - 「予約履歴_バックアップ」シートに保存

4. **手動復元機能**
   - メニューから簡単に復元可能
   - 「🔄 バックアップから復元」

## 📖 使い方

### メニュー機能

#### 実行系
- **今すぐ実行 (クリーン)**: 手動で即座に実行
- **今すぐ実行 (安全版/ロック付き)**: ロック機能付きで実行
- **重複削除(最新を残す)**: 重複データを削除
- **初期作成**: シートを初期化

#### バックアップ系
- **🔄 バックアップから復元**: バックアップシートからデータを復元
- **💾 手動バックアップ作成**: 手動でバックアップを作成

#### 自動実行系
- **⚙️ 自動実行ON (5分ごと)**: トリガーを設定して自動実行を開始
- **⚙️ 自動実行OFF**: 自動実行を停止
- **⚙️ トリガー状態を確認**: 現在のトリガー設定を確認

## 🗂️ データ構造

### ソースシート（シート2）
- Pythonスクリプトが30分ごとに更新
- 「今日以降」のデータのみ（日付変わると昨日分は消える）
- キャンセル含む全予約データ

### 蓄積シート（予約履歴_蓄積）
- 過去データも全て保持
- キャンセル履歴も含む
- 重複は自動で削除（最新データを保持）

### 管理列
- **抽出日時**: データを取り込んだ日時
- **抽出日**: データを取り込んだ日付
- **抽出元**: データの取り込み元シート名

---

## 🔑 キー設定

重複判定に使用する列：
- 予約番号
- 予約状態
- 日付
- 開始
- 終了

これら5つの値が完全一致する場合、同じ予約と判定され、最新の「抽出日時」を持つデータのみが保持されます。

## ⚠️ トラブルシューティング

### データが消えた場合

詳細は `データ復旧手順.md` を参照してください。

**簡易手順：**
1. ファイル → 変更履歴 → 変更履歴を表示
2. データがあった時点の履歴を探す
3. 「この版を復元」をクリック

### エラーが出る場合

#### ロックエラー
```
ただいま他の店舗が予約履歴を更新中です。
```
→ 数分待ってから再実行

#### シートが見つからない
```
シートが見つかりません
```
→ メニューから「初期作成」を実行

   - 最新バージョンを選択

## 🛡️ セキュリティ

### ロック機能
- `LockService` を使用して同時実行を制御
- 複数店舗から同時にアクセスしても安全
- 30秒のロック待機時間

### データ保護
- 自動バックアップで万が一に備える
- Googleスプレッドシートの変更履歴で復元可能
