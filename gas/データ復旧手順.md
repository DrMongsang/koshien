# 📋 11月データ復旧手順

## 🔍 問題の原因

### 1. **7日間フィルタの問題**
- `inDateWindow()` 関数が過去7日間のデータのみを許可していた
- 12月9日時点で11月のデータは7日以上前なので、新規追加時にスキップされていた

### 2. **dedupeDest()のリスク**
- `sh.clearContents()` でシート全体をクリアしてから書き戻す処理
- 処理中にエラーが起きるとデータが全消失する可能性があった

---

## 🛠️ 修正内容

### ✅ 修正版で追加・改善された機能

1. **日付フィルタを削除**
   - 過去データも含めて全てのデータを保持するように変更
   - `run()` 関数から `inDateWindow()` チェックを削除

2. **安全な重複削除処理**
   - `clearContents()` → `deleteRows()` に変更
   - データ消失リスクを低減

3. **自動バックアップ機能**
   - 処理実行前に自動でバックアップを作成
   - 「予約履歴_バックアップ」シートに保存

4. **手動復元機能**
   - メニューから「🔄 バックアップから復元」で簡単に復元可能

---

## 📝 データ復旧手順

### 方法1: Googleスプレッドシートの履歴から復元（推奨）

1. スプレッドシートを開く
2. **ファイル → 変更履歴 → 変更履歴を表示** をクリック
3. 右側に履歴が表示される
4. **11月のデータがあった時点**の履歴を探す
   - 日付とタイムスタンプで判断
   - 「データが消える前」の状態を見つける
5. その履歴をクリックして内容を確認
6. 問題なければ「**この版を復元**」をクリック

### 方法2: バックアップシートがある場合

もし「予約履歴_バックアップ」シートが既に存在し、11月のデータが含まれている場合：

1. GASエディタで修正版コードに更新
2. メニューから「🔄 バックアップから復元」を実行
3. 確認ダイアログで「はい」をクリック

### 方法3: 手動でデータを復元

1. 変更履歴から11月データがある版を開く
2. 「予約履歴_蓄積」シートのデータをコピー
3. 新しいシート（例：「復旧用_11月データ」）を作成
4. そこに貼り付け
5. 修正版のコードをデプロイ後、手動で統合

## 🚀 修正版の適用手順

### Step 1: GASエディタで修正版を適用

1. **Google Apps Scriptエディタ**を開く
2. 既存のコードを**全て選択して削除**
3. `gas/予約履歴システム_修正版.gs` の内容を**コピー&ペースト**
4. **保存**（Ctrl+S または ⌘+S）

### Step 2: テスト実行

1. メニューから「初期作成」を実行（初回のみ）
2. メニューから「今すぐ実行 (安全版/ロック付き)」を実行
3. エラーが出ないことを確認

### Step 3: ライブラリをデプロイ（バージョンアップ）

1. **デプロイ → デプロイを管理** をクリック
2. 鉛筆マーク（✏️）をクリックして編集
3. **バージョン**を「新バージョン」に変更
4. 説明欄に「データ消失バグ修正 + バックアップ機能追加」などと記入
5. **デプロイ**をクリック

### Step 4: 11店舗の日報システムで更新

各店舗のスプレッドシートで：
1. **ツール → スクリプトエディタ** を開く
2. 左側のメニューから **ライブラリ +** をクリック
3. 該当のライブラリの右側にある **更新マーク** をクリック
4. バージョンを**最新版**に変更
5. **保存**

## 🆘 困ったときは

### データが見つからない場合

1. **変更履歴を徹底的に調べる**
   - 数日分さかのぼって確認
   - 「データ件数が多い版」を探す

2. **シート2（ソース）を確認**
   - Pythonスクリプトが取得した元データが残っている可能性

3. **他の店舗のデータを確認**
   - 同じ予約が他店舗のシートにも記録されている可能性

### エラーが出る場合

1. **ロックエラー**
   ```
   ただいま他の店舗が予約履歴を更新中です。
   ```
   → 数分待ってから再実行

2. **シートが見つからない**
   ```
   シートが見つかりません
   ```
   → メニューから「初期作成」を実行

3. **その他のエラー**
   - GASエディタの「実行ログ」を確認
   - エラーメッセージをコピーして記録
